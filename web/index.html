SRA Conversion Evaluator

Build an SRO floorplate as a working model — move rooms along the corridor, drag the partitions between them to trade area, add or remove rooms, and knock walls out to merge. The tool tests the resulting scheme against the three numeric thresholds in the sources, each reported with its own citation, and separates rooms lost from tenants permanently displaced.

Tenancy drives the compensation schedule and cannot be drawn, so it is typed. Marking a room SRA leaves it unconverted: it survives the project as a designated room, and its partitions cannot be removed.

Scope. One floorplate at a time. The tool evaluates a scheme you propose; it does not search for a compliant one. It does not model the permit process, financial-viability findings, rent-setting, or whether a merge is physically buildable. The model is diagrammatic: rooms are single-loaded off one corridor at an assumed 12′ depth, and width follows area. Partitions are drawn at 3′ so the plan reads from above. Pod program comes from SRA Guidelines p.5–6, which dimensions only the refrigerator (24″×24″); the bathroom (5′×8′) and kitchen run (8′×2′) are conventional minimums stated here as assumptions.
