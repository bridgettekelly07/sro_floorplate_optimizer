## SRO Floor Plate Optimizer
A tool for optimizing SRO floorplates according to the guidelines

The SRO Guidelines lets a building remove rooms from SRO designation by merging them into self-contained units of at least 200 sq ft each (or 200 sq ft on average if some fall short), capped at losing no more than 50% of the original room count. The tool takes a corridor's actual room sizes, tests merge combinations against both the 200 sq ft and 50%-loss rules, and shows in Rhino which merge pattern yields the most compliant units — or that no compliant pattern exists for that floor plate.
